# Stress AI Coach — marketing site

Landing page (14 sections) + 60-second stress-pattern quiz funnel for the Stress AI Coach iOS/watchOS app. Next.js 15 App Router, Tailwind CSS 4, server components throughout with two small client islands (`Nav` mobile sheet, quiz flow).

## Run

```bash
cd landing
npm install
npm run dev        # http://localhost:3000
```

## Build & test

```bash
npm run build      # production build to .next/
npm run test       # vitest — quiz scoring engine tests
```

## Routes

| Route | What it is |
| --- | --- |
| `/` | Landing page, sections S1–S14 (hero → footer) |
| `/start` | Client-side quiz: 7 questions → stress pattern → result card → App Store CTA |
| `/sitemap.xml`, `/robots.txt` | Generated by `app/sitemap.ts` and `app/robots.ts` |

## Single places to edit

- **App Store URL** — `site.config.ts` `appStoreUrl` (placeholder `idXXXXXXXXX` until the ASC app exists). Every CTA on the site reads from here.
- **Canonical domain** — set at deploy time, in two spots that must match:
  - `app/sitemap.ts` and `app/robots.ts` (currently `https://PLACEHOLDER.vercel.app`)
  - `SITE_URL` in `app/layout.tsx` (`metadataBase`, resolves absolute Open Graph URLs)

## Deploy (Vercel)

Import the repo in Vercel: **New Project →** set **Root Directory** to `landing/` — the framework preset (Next.js) is detected automatically. Then replace the placeholder domain listed above with the assigned Vercel/production domain.
