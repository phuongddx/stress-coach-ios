## 5. Quiz funnel — `/start`

**Flow:** intro → 7 single-choice steps (large tappable cards, "3 of 7" progress) → computing beat (Ripple pulse ~1.2s) → result card → CTA.

**Scoring:** each answer adds weights to 5 patterns (data in `content/quiz.ts`); result = argmax + secondary.

| Pattern | Answer signals | Result promise (real app features) |
|---|---|---|
| Sleep Debt | wake tired, <6.5h, late bedtime | sleep factor, wind-down nudges, morning trends |
| Overload | can't switch off, working late, always reachable | high-stress alerts, in-the-moment resets |
| Overstimulation | caffeine, screens, noise, no breaks | breathing resets, stimulus check-ins |
| Stagnation | sitting all day, low movement | activity factor, mini-walk resets |
| Irregular Rhythm | skipped meals, shifting schedule, weekend drift | rhythm patterns, trend calendar |

**Result card:** pattern name + "this is you because…" (derived from answers) + "what your coach focuses on" (3 bullets) + mood-face SVG + "Start with this plan" App Store CTA + secondary "See how the score works" (landing §4 anchor).

**Explicitly out:** countdowns, fake scarcity, email capture, web paywall.

## 6. Design system

- **Tokens (`tokens.css`, verbatim from `sac-landing.html` / app Theme):** ink `#101223`, muted `#6B6E7B`, accent `#0288D1`, accent-bright `#4FC3F7`, ripple-tint `#E1F2FC`, surface `#F2F2F7`, warm surface `#FFFDF6`, tiers `#00A000/#007AFF/#8A5A00/#B25400/#FF3B30`, gradient `#4FC3F7→#0288D1→#10B981`
- **Type:** Roboto (display + body; weights 400/500/700, self-hosted woff2 — `next/font` in the build), mono stays `ui-monospace`. Applied to `sac-landing.html` 2026-09-07 on user request (was system serif/sans stacks)
- **Layout:** 12-col grid, ~1180px max width, rounded 18–24px cards, soft shadows
- **Motion:** white→tint hero transition, staggered scroll reveals, animated tier viz, breathing ring, gentle Ripple float; all gated by `prefers-reduced-motion`
- **Illustration rule:** all visuals authored SVG/illustration — **no app screenshots anywhere** (per design decision, 2026-09-07)

## 7. Tech architecture

- Next.js App Router + TypeScript, Tailwind v4 + `tokens.css` layer; all routes prerendered
- `components/landing/*` (14 sections), `components/funnel/*` (QuizFlow, QuestionCard, ProgressBar, ResultCard), shared (AppStoreBadge, SectionHeading, MoodTierStrip, illustrations as inline React SVG components)
- Content data: `content/quiz.ts`, `content/faq.ts`, landing copy co-located
- Assets: SVGs from Open Design project + `design/exports/` (inline React components preferred; `<img>` for character/mood SVGs where animation isn't needed)
- SEO: metadata API per route, static 1200×630 OG image, `sitemap.ts`, `robots.ts`, JSON-LD `SoftwareApplication`
- Analytics: none in v1

## 8. Content integrity & legal constraints

- **No fabricated social proof** — no testimonials, user counts, review scores, "featured in" claims (app unreleased). Trust strip uses verifiable facts only
- **No medical claims** — behavioral framing ("notice patterns"), footer "not medical advice" line, FAQ states it explicitly
- **No dark patterns** — no countdowns, no scarcity, funnel ends at App Store CTA
- Legal links point at existing docs-site privacy/terms; support email real (`support@stressmonitor.app`)
- App Store URL is a config constant until the ASC app ID exists — never hardcode per-CTA
